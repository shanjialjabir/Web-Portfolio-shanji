# Shanji Aljabir — Application Portfolio

Versi portofolio yang dirancang untuk kebutuhan lamaran kerja entry-level bidang
IT sebagai fresh graduate Informatika, dengan pengalaman Graphic Design,
Filmmaking, Video Editing, dan Commercial Video Directing sebagai nilai tambah.

## Isi utama

- profil profesional yang ringkas dan mudah dipindai recruiter;
- pengetahuan dasar IT dari perkuliahan dan keterampilan produksi kreatif;
- soft skills yang relevan untuk pekerjaan teknis;
- karya film dan desain terpilih;
- proyek terbaru “Ini Bukan Brand New Day” dengan peran sebagai Director;
- pengalaman kerja dan pendidikan;
- kontak, LinkedIn, dan Instagram.

Untuk melihatnya, buka `index.html` di browser. Seluruh gambar utama sudah
tersimpan di folder yang sama sehingga website bisa dipasang langsung di
GitHub Pages.
